## 🛠️ Stack Tecnológico

- **Estructura & UI:** HTML5 semántico, Tailwind CSS (configurado en modo daylight spatial).
- **Gráficos 3D:** Three.js (r128).
- **Animaciones & Coreografía:** GSAP 3 (GreenSock) + ScrollTrigger.
- **Iconografía:** Lucide Icons.
- **PWA & Interactividad:** JavaScript moderno vanilla, soporte offline y layouts responsivos.

## 🚀 Despliegue en GitHub Pages

Este repositorio está estructurado con `index.html` en la raíz para habilitar GitHub Pages con un solo clic:

1. Ve a **Settings** > **Pages** en este repositorio.
2. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**. Tu sitio estará disponible en:
   `https://lordonezvirtual.github.io/leocv/`
